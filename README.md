# Projeto PRACDR

# Sobre o projeto
Hoje resolvi mostrar meu projeto mais recente. Feito em Julho de 2026, eu desenvolvi o protótipo chamado PRACDR, um sistema desenvolvido para o SUS. A ideia para esse projeto surgiu de uma forma interessante, a Supervisão do SUS da Região Sul de São Paulo, solicitou para mim um auxilio com uma ideia de melhoria que eles tinham para o sistema do SUS, eles queriam reunir todas as pessoas com Doenças Raras em um único sistema. 

# Desenvolvimento 
Tendo sido desenvolvido apenas por mim, pude experimentar como é a produção total de um sistema a partir do zero. Esse projeto traz alguma funções para o usuário, ele reúne os pacientes cadastrados, seus dados, acompanhantes e informações de contato, tanto do paciente quanto do próprio acompanhante. 
Esse projeto foi desenvolvido em Windows Forms pela linguagem C#. Foi uma experiência muito proveitosa pois pude aprender mais da linguagem e, também, aproveitar mais para entender o funcionamento do gerenciamento de dados, pois, inserir dentro do próprio sistema, um banco de dados local para que os arquivos dos pacientes não fossem perdidos. 

# Objetivos
  1. Aplicação de um sistema específico para pacientes com Doenças Raras;
  2. Agilização do processo de buscas;
  3. Cadastramento personalizado para pessoas com diagnósticos específicos;
  4. Acompanhamento facilitado dos pacientes para retirada de remédios e insumos;
  5. Produção automatizado de relatório com todas as informações e histórico do paciente.

# Objetivos futuros
Futuramente, o sistema pode sim ser melhorado com a adição de novas funções. A ideia primordial, como função básica, seria a possibilidade de exclusão e de edição de cada paciente, essas funções não foi adicionadas em primeira instância pois, o projeto ainda é apenas para demonstração e precisa passar por uma aprovação ainda. Outra evolução possível é fazer uma aba para o sistema que coloque separado os pacientes que possam vir a necessitar de alguma doação especial, como por exemplo doação de órgãos ou de medula.
